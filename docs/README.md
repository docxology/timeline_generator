# Timeline Generator documentation

Timeline Generator combines a React and D3 browser interface with a Fastify
API and a Neo4j graph store. It represents people as nodes, relationships
as typed edges, and events as dated records attached to people. The
included Fuller network is a seed dataset for exploration.
