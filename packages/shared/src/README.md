# shared/src/

Source code for the shared types, schemas, and constants package.

| File | Contents |
|------|----------|
| `types.ts` | TypeScript interfaces: Person, Edge, TemporalEvent, Place, Source, FocalGraph, etc. |
| `schemas.ts` | Zod schemas for runtime validation + Create/Update variants |
| `constants.ts` | Enums (EdgeType, EdgeCategory, EventType, DatePrecision, EdgeDirection), color maps, confidence tiers, layer presets |
| `index.ts` | Barrel re-export |
| `__tests__/` | 72 tests (constants, schemas, exports) |
