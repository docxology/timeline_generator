# frontend/src/components/

React components for the sidebar panels and modal overlays.

| Component | Description |
|-----------|-------------|
| `LeftPanel.tsx` | Person directory with search, domain dots, layer controls |
| `RightPanel.tsx` | Person detail or edge inspector (mutual exclusive views) |
| `ResearchPanel.tsx` | Perplexity research modal (Escape to close, auto-focus) |
| `LayerPanel.tsx` | Edge category toggles, presets, confidence slider |
